# Portal Acadêmico Digital

Projeto acadêmico desenvolvido para praticar conceitos de DevOps, colaboração em equipe, branches, commits, Pull Requests, integração contínua e publicação com GitHub Pages.

## Objetivo

O objetivo do projeto é desenvolver e evoluir um Portal Acadêmico utilizando um fluxo colaborativo no GitHub. Cada integrante ficou responsável por uma alteração, trabalhando em uma branch separada e enviando a mudança por meio de Pull Request.

## Fluxo de trabalho

O desenvolvimento foi realizado com branches separadas para cada alteração. Cada integrante fez commits em sua branch e abriu um Pull Request para a branch `main`.

Os testes automáticos foram executados pelo GitHub Actions. As alterações foram integradas à `main` depois da verificação do CI.

Durante a alteração do cálculo da média, o teste automático identificou um erro. A fórmula foi corrigida e os testes voltaram a passar.

## Como analisar o histórico

O histórico do projeto pode ser conferido pelas seguintes áreas do repositório:

- **Commits:** mostra as alterações realizadas ao longo do projeto;
- **Branches:** mostra as frentes de trabalho da equipe;
- **Pull Requests:** mostra as alterações propostas e integradas;
- **Actions:** mostra os testes automáticos e as publicações;
- **Issues:** registra os requisitos e ajustes do projeto.
